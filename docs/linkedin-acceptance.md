# LinkedIn recovery and verification integration

Official sources checked 10 October 2026. This is general product research, not
an account-specific support record. No person or platform has been contacted and
no recovery request, document or verification result has been submitted.

## What LinkedIn currently accepts for recovery

LinkedIn directs restricted-account identity checks through its Persona flow.
The flow accepts supported valid government identification and can require a
selfie matched to the document portrait. Accepted documents depend on the
issuing country and the options actually offered in the recovery session.
[LinkedIn recovery instructions](https://www.linkedin.com/help/linkedin/answer/a1342692?lang=en)

When password and two-factor authentication already succeed but face matching
fails, repeating password recovery does not address that failure. Persona says
that after a limited number of failed verification attempts the person needs to
contact LinkedIn directly. Its guidance also permits trying another accepted ID
type when available. A successful retry or restoration is not promised.
[Persona's LinkedIn recovery guidance](https://help.withpersona.com/en-US/end-users/linkedin/account-recovery/)

For Australia, do not assume a notarized affidavit is an available substitute.
LinkedIn's current recovery article limits its published affidavit alternative
to Canada, the EU and the UK. An older PDF named "Non-US-Affidavit" does not
establish Australian eligibility under the current instructions. A different
method would need confirmation from LinkedIn for the actual case.
[Current alternative-method eligibility](https://www.linkedin.com/help/linkedin/answer/a1342692?lang=en)

## A legitimate next request after a facial mismatch

Use the support or appeal path offered in the account's restriction notice or
existing case. LinkedIn's official restrictions article directs affected
members to the login prompts. Its ordinary Help Center support route requires
sign-in, so that route may itself be inaccessible during a restriction.
[Account restrictions](https://www.linkedin.com/help/linkedin/answer/a1340522),
[current support instructions](https://www.linkedin.com/help/linkedin/answer/a518597)

A useful case description would distinguish completed account authentication
from the failed face-to-document comparison, give the exact error and relevant
attempt dates, and request human review or an alternative accepted verification
method that accommodates legitimate changes in appearance. This is a proposed
request, not a published guarantee that LinkedIn provides that specific review.
Keep case identifiers, ID images and personal information in private records.

The commonly referenced official-domain appeal URL
`https://www.linkedin.com/help/linkedin/ask/TS-F-APPEAL` did not render through the
research browser. Its present availability and form requirements were not
verified; use the actual account notice or case instructions as the authority.
No reliable account-restoration deadline was established by this research.

## What our package can demonstrate

The package can make one-to-one comparison results, quality gates, signed
evidence bindings and decision assumptions inspectable. A research result is
not an accepted LinkedIn credential. No published self-service route was found
in the cited recovery or integration documentation for replacing Persona's
recovery decision with a third party's independently generated assertion.

Any proposed use as supporting material requires LinkedIn's agreement on what
it will accept. Company registration and possible future Australian Digital ID
accreditation must not be represented as LinkedIn acceptance. The implementation
currently supplies no production accreditation or calibrated identity guarantee.

## API integration is a separate product route

The Verified on LinkedIn APIs let an approved application obtain a consenting
member's existing LinkedIn verification information. The documented direction is
from LinkedIn to the application. For an unverified member, the API can return a
LinkedIn verification URL. It does not document a facility for uploading this
package's result to unlock a restricted LinkedIn account.
[Verified on LinkedIn overview](https://www.linkedin.com/help/linkedin/answer/a9385085),
[official API FAQ](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/verified-on-linkedin/faq)

Likewise, optional profile identity badges and workplace badges serve a separate
purpose from restricted-account recovery. Completing or integrating one should
not be described as bypassing the other.
[Optional Persona profile verification](https://www.linkedin.com/help/linkedin/answer/a1714211),
[LinkedIn recovery instructions](https://www.linkedin.com/help/linkedin/answer/a1342692?lang=en)
